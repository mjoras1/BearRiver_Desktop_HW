# Agent instructions

- After each request, add an entry to prompts.md: what I asked, what you changed, and whether it worked.

## Project files

- Keep the Tkinter desktop application in `app.py`.
- Keep setup and launch instructions in `README.md`.
- Keep the application requirements and validation instructions in `spec.md`.
- Record each user request, resulting changes, and verification outcome in `prompts.md`.
- Do not claim live-data or calculation validation unless it has actually been completed.

## Working conventions

- Use Tkinter for the desktop user interface.
- Keep changes focused on the user's request and preserve existing project files.
- Run `python -m py_compile app.py` after changing Python code.
